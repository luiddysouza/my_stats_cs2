## Dev Notes

### Tech Preset de Referência
> Usar `.aiox-core/data/tech-presets/flutter.md` como guia de padrões, estrutura e stack.

### Decisão de OQ-02 (Rating)
> Rating usa `double` no range 0.0–2.0, padrão HLTV 2.0. Esta decisão foi tomada durante a critique da spec (G-03 em `docs/spec/critique.json`) para evitar retrabalho ao integrar a API futura.

### Contrato do Mock Data (AC-09)
> O mock data em `lib/core/mocks/mock_data.dart` deve usar exatamente os mesmos campos e tipos das entidades de domínio. Quando a API real for integrada no futuro, apenas o `datasource` mudará — o domínio e a UI permanecem intactos.

### Padrão de Const
> Usar `const` em todos os construtores de widgets e entidades imutáveis. O `flutter analyze` com `flutter_lints` irá reportar warnings para `const` ausentes.

### Sem Testes Complexos nesta Story
> Esta story foca em estrutura e configuração. O teste padrão gerado pelo `flutter create` é suficiente. Testes de feature serão adicionados nas Stories 1.2 e 1.3.
